安装

  1. 点上面的按钮下载 selfagent-0.1.0.apk。
  2. 打开文件；系统提示时允许「安装未知来源应用」。
  3. 安装完成后打开，填入 DeepSeek API Key。
  4. 到「设置」授权日历、通知、精确闹钟。

让它可靠提醒

  • 小米设置 → 应用设置 → 应用管理 → SelfAgent → 自启动。
  • 应用信息 → 省电策略 → 无限制。
  • 多任务界面下拉 SelfAgent，锁定后台。
  • 外屏找不到：设置 → 外屏 → 外屏应用；或用 MixFlipTool 强制加入。
安装被拦截 / 下载很慢？

APK 使用 debug 签名，部分手机会提示「未经安全检测」，选择继续安装即可。GitHub 在国内可能较慢，可以复制下载链接到电脑下载后传到手机。
